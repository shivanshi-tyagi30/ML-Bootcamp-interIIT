# Trace: AI meeting assistant

Upload a meeting recording to get a raw transcript, a refined transcript, and minutes, decisions, action
items and open proposals that are grounded in the transcript.

Paste your own free Gemini API key (aistudio.google.com -> Get API key) in the app's API key box. It is kept
in your browser and in server memory only, never written to disk.
